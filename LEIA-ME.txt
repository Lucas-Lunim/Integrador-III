PROJETO INTEGRADOR III — COLETOR SQLITE

1. Extraia todos os arquivos do ZIP para uma pasta sua.
2. Abra INICIAR-COLETA.cmd com dois cliques.
3. Digite o endereço atual da API industrial, o mesmo configurado no
   painel exploratório. Exemplo de formato: http://IP_DO_SERVIDOR:8080
   Use o endereço real no lugar de IP_DO_SERVIDOR.
4. Deixe a janela aberta durante a coleta. Para parar, pressione Ctrl+C.

O script usa Python 3 e as bibliotecas que já vêm com ele. Não precisa de
pip, de instalar o SQLite separadamente ou de manter o HTML aberto.
O computador precisa conseguir acessar a API pela rede do laboratório.

O banco leituras_industriais.db fica junto do script e já inclui os dois
CSVs enviados no projeto (26/10 e 03/11). O coletor consulta /maquinas a
cada 5 segundos e grava cada lote antes de consultar de novo. A mesma
combinação de máquina, ID da origem e horário ocupa uma linha no histórico.
Um ID pode ser reutilizado pela API em outro horário sem apagar a leitura antiga.

COMANDOS OPCIONAIS
Abra o PowerShell na pasta que contém o script e execute:

  python .\coletor_sqlite.py coletar --api http://IP_DO_SERVIDOR:8080
  python .\coletor_sqlite.py importar "C:\caminho\leituras.csv"
  python .\coletor_sqlite.py exportar historico.csv
  python .\coletor_sqlite.py backup copia_leituras.db

Use --uma-vez depois de coletar para testar a conexão e gravar só um lote.
Use --intervalo 2 depois de coletar para consultar a cada 2 segundos.
Para atualizar o dashboard HTML, gere um CSV e importe-o pelo painel.

O QUE FICA NO BANCO
- leituras: horário em UTC, máquina, ID, status e métricas em colunas.
  Campos ausentes ficam vazios; não são convertidos em zero.
- originais: dados de origem, incluindo campos extras da API ou do CSV e
  eventuais diferenças entre o que veio da API e o que foi importado.
- registros_invalidos: dados sem identificação ou horário válido, com
  o motivo pelo qual ficaram fora do histórico principal.

A API mantém as leituras em memória temporária. Se a coleta ficar parada
ou a rede cair por tempo suficiente, as leituras que expirarem na API
antes de serem coletadas não poderão ser recuperadas por este script.
Para proteger o arquivo já salvo, use o comando de backup e guarde a
cópia em outro local.
