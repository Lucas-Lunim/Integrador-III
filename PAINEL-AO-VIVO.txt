MONITOR INDUSTRIAL AO VIVO — PROJETO INTEGRADOR III

1. Feche a janela do coletor antigo, caso esteja aberta.
2. Na pasta do coletor, dê dois cliques em ABRIR-PAINEL.cmd.
3. Digite o endereço atual da API industrial, como no coletor anterior.
4. O dashboard abre no navegador. Se não abrir, digite:
   http://127.0.0.1:8765

O atalho faz a coleta e abre o painel usando o mesmo banco
leituras_industriais.db. Mantenha a janela do coletor aberta enquanto
quiser receber novas leituras. A coleta continua se fechar o navegador.

Ao vivo mostra os últimos 30 minutos. Se não houver dados recentes,
o painel sinaliza isso e mostra o último dia salvo. Escolha uma data
no filtro para consultar o histórico e clique em uma máquina para ver
seu gráfico, suas condições e suas leituras.

Por padrão, a API é consultada a cada 5 segundos e o navegador verifica
o banco a cada 2 segundos. Se a API ficar indisponível, o painel
mostra o estado e o coletor volta a tentar automaticamente.
